# Staq queue icon

Generated with the built-in imagegen tool. `source.png` is the original image with transparency. Platform icons were exported with `npm run tauri -- icon src-tauri/icons/queue/source.png --output src-tauri/icons/queue`. The browser favicon is copied from `128x128.png` to `public/staq-icon.png`.

## Generation prompt

Use case: logo-brand. Asset type: square desktop application icon for a minimal task queue app. Primary request: schematically depict a queue of tasks using small blocks of different colors. Create one crisp flat geometric icon, 1024x1024, centered on a genuinely transparent background. Subject: exactly four equal-size horizontal rounded rectangular blocks arranged vertically one above another in a neat queue, with clear generous even gaps. Each rectangle is about 55 percent of the canvas width and 13 percent of canvas height. Entire stack occupies about 70 percent of canvas height. From top to bottom: warm coral, golden amber, muted sky blue, deep sage green. Simple solid color fills with excellent contrast. Modest corner rounding. Straight front view. Minimal, balanced, clean silhouette that reads at 32x32. No surrounding tile or container, no text, letters, checkmarks, dots, lines within blocks, arrows, outlines, perspective, shadows, gradients, texture, or watermark. Deliver just the single finished icon, not a presentation sheet.
